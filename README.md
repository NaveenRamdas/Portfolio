# Naveen R — AI-Native Frontend Engineer Portfolio

Premium personal portfolio built with Next.js 15, TypeScript, Tailwind CSS, and Framer Motion.

## Stack

- **Framework**: Next.js 15 (App Router) + TypeScript
- **Styling**: Tailwind CSS with custom design system
- **Animations**: Framer Motion (scroll-triggered, page reveal, hover depth, parallax)
- **UI**: Glassmorphism, gradient borders, glow effects, dark theme
- **Icons**: Lucide React + custom SVG icons

## Sections

1. **Hero** — Animated typewriter titles, floating tech icons, mouse-parallax blobs, CTA buttons
2. **About** — Animated stats counters, career journey timeline, capability highlights
3. **Skills** — Categorized skill cards with animated progress bars and glow hover effects
4. **Experience** — Expandable vertical timeline with achievement lists
5. **Projects** — 3D tilt cards with spotlight hover, tech stack badges, live/code links
6. **AI-Native** — Animated terminal simulation, AI workflow steps, tool showcase
7. **GitHub Stats** — Contribution graph visualization, top languages, activity metrics
8. **Impact** — Metrics showcase + testimonials from colleagues
9. **Contact** — Animated form with send simulation, social links, availability status
10. **Footer** — Social links, nav, back-to-top

## Features

- `⌘K` Command palette for keyboard navigation
- Loading screen with progress animation
- Particle background with mouse interaction
- Scroll progress indicator
- Responsive mobile-first design
- SEO metadata + OpenGraph
- Static export optimized

## Run Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Deploy to Vercel

```bash
npm install -g vercel
vercel
```

Or connect your GitHub repo to [vercel.com](https://vercel.com) for automatic deployments.

## Customization

Update `src/lib/constants.ts` with your real:
- GitHub/LinkedIn URLs and email address
- Project details and live demo links
- Resume PDF (replace `public/resume-naveen-r.pdf`)
